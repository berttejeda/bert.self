## Featured work

<div class="grid cards" markdown>

-   **[ansible-taskrunner](https://github.com/berttejeda/ansible-taskrunner)**

    ---

    A wrapper around `ansible-playbook` that turns specially formatted playbook vars into a full
    [Click](https://click.palletsprojects.com/) CLI — options, subcommands, help text and embedded shell functions.
    My most-used project: 440+ commits, 33 PyPI releases.

    `Python` `Ansible` `CLI`

-   **[bert.validator](https://github.com/berttejeda/bert.validator)**

    ---

    A Go command-line tool that runs shell-based validation tests from a YAML manifest, with
    Sprig templating, tag filtering, includes, loops, conditional execution and a run summary.
    Distributed with a Homebrew formula.

    `Go` `YAML` `Testing`

-   **[bert.ops-command](https://github.com/berttejeda/bert.ops-command)**

    ---

    A single `ops` entrypoint that discovers your shell scripts and exposes them as consistent,
    self-documenting subcommands — a common front door for day-to-day operations work.

    `Bash` `Developer Experience`

-   **[bert.dashboard](https://github.com/berttejeda/bert.dashboard)**

    ---

    A React + Flask app for interactive, Jinja-templated, Markdown-based lessons with a built-in
    web terminal. Successor to [bert.bill](https://github.com/berttejeda/bert.bill).

    `React` `Flask` `xterm.js`

</div>
